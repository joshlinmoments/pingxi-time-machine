# 平溪老街 AI 時光機 · 回到平溪那年

> 跟著平溪最強嚮導「小葉」，一站一站走進老街，用五感與相機，穿越回到平溪的那些年。

一款**手機優先的走讀遊戲**，改編自白陽山基金會「回到平溪那年」實體任務卡。玩家沿平溪老街實地走訪 7 個景點，透過對話式劇情、感官在地任務與拍照，完成後生成專屬「平溪明信片」。

## 玩法特色
- **對話式 AI 嚮導小葉**：一句句帶路的劇情引擎（v1 為腳本，未來可換真 LLM）
- **時光機場景**：每關翻出「回到那年」的卡通插畫
- **感官在地任務**：聽鳴笛、讀對聯、數香、摸布、嚐芋圓——非到現場做不到
- **有標準答案的題會判對錯**（答對才過關）；開放題只給小葉暖回應
- **我的平溪相簿**：選拍真實照片存本機（自動壓縮、不上傳、隱私安全）
- **結尾自動拼貼明信片**，可儲存分享

## 七關動線
火車站 → 成盈利商店 → 新建成百貨行 → 觀音巖 → 平溪後山（躲貓貓）→ 美雲布藝工作室 → 平溪芋圓（小葉請客）

## 技術
單一 `index.html`，原生 JS + `localStorage`，無後端、可離線。手機瀏覽器可叫用相機拍照。
